# User-Configuration-Manager

A simple Python project for managing user configuration settings such as theme, language, notifications, and volume.

## Features

* Add new settings
* Update existing settings
* Delete settings
* View current settings
* Case-insensitive setting keys and values
* Handles missing or duplicate settings with clear messages

## Concepts Practiced

This project demonstrates fundamental Python concepts including:

* Dictionaries and tuples
* Functions and parameters
* `if` / `else` statements
* `for` loops
* Dictionary methods such as `.items()`
* String methods such as `.lower()` and `.capitalize()`
* `return` statements
* Formatted strings (f-strings)
* Dictionary item deletion with `del`

## Purpose

This project was created as a practice exercise to strengthen Python fundamentals and gain hands-on experience working with dictionaries, functions, and user configuration data.
